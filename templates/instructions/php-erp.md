## 7. PHP ERP 특화 규칙

- DB 쿼리는 **PDO prepared statement** 만 사용한다. 문자열 직접 이어붙이기 금지.
- DB 구조(테이블/컬럼)를 바꿔야 하면 코드보다 먼저 `sql/` 폴더에 `YYYYMMDD_설명.sql` 파일을 만든다.
- DB 에러 메시지를 사용자 화면에 그대로 보여주지 않는다. (로그로만 남긴다)
- 모든 관리 페이지는 로그인 세션을 먼저 확인한다.
- 파일명과 클래스명은 기존 ERP 파일 구조와 이름 규칙을 그대로 따른다.
- PHP 8.x, 들여쓰기 4칸(스페이스).
