## 7. 정적 디자인/프론트엔드 특화 규칙

- HTML/CSS/JS 만으로 구성한다. 외부 라이브러리는 사용자 승인 후에만 추가한다.
- 모바일 우선(mobile-first) 반응형으로 작성한다. 390px / 768px / 1280px 기준점을 확인한다.
- CSS 변수(`--color`, `--spacing` 등)로 디자인 토큰을 관리한다.
- 이미지/아이콘은 최적화된 형식(WebP, SVG 우선)을 사용한다.
- JS는 순수 Vanilla JS 또는 이미 사용 중인 프레임워크를 따른다.
- `console.log` 디버그 코드는 배포 전에 제거한다.
